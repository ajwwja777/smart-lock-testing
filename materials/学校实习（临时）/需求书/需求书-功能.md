# 1       硬件需求说明书

l  智能锁基础硬件应包含微控制器、通信模块、指纹识别模块、RFID读写模块、反馈模块（器件）……；

l  智能锁应能匹配市面常见的入户门锁或对已有锁进行有限的改造即可安装；

l  智能锁能源供给：

n  智能锁采用AA电池供电；

n  当供电电池能量不足时，可临时改用外接直流电源供电；

# 2       软件需求说明书

l  身份认证功能

n   多模开锁：支持指纹、密码、手机 NFC、蓝牙、机械钥匙等五种以上开锁方式，适配不同场景需求。

n   活体指纹识别：采用半导体指纹头，可识别真实皮肤生物电特征，有效防范假指纹破解。

n   虚位密码技术：允许在正确密码前后输入任意数字干扰项，防止密码被偷窥盗取。

l  远程管理功能

n   状态实时监控：通过 APP 查看门锁开关状态、电池电量、开锁记录等信息。

n   临时密码生成：可设置时效型临时密码供访客使用，支持一次性密码或周期性授权。

n   异常报警推送：当检测到撬锁、试错、低电量等异常情况时，立即向手机发送通知。

l  安全防护功能

n   防试错锁定：连续错误输入 5 次以上自动锁定，需管理员验证后解锁。

n   胁迫指纹报警：预设特定指纹，在遭遇胁迫时开锁同时向紧急联系人发送求救信息。

n   电磁防护设计：内置法拉第笼屏蔽层，抵御特斯拉线圈等强电磁攻击。

l  便捷辅助功能

n   一键布防模式：外出时通过物理按键快速启动布防状态，联动智能家居设备进入安防模式。

n   应急供电接口：配备 Type-C 应急充电口，在电池耗尽时可外接充电宝临时供电开锁。

n   低电量提醒：剩余电量低于 10% 时，通过语音、APP 推送等多渠道预警。

l  智能联动功能

n   场景自动化：与智能家居系统联动，实现开门自动开灯、关闭窗帘、启动空调等场景。

n   AI 学习优化：通过分析用户使用习惯，自动调整指纹识别灵敏度或休眠模式。
